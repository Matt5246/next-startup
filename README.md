
# Next.js Project Template

Includes essential tools and features to accelerate development.

## ✨ Features

This template comes pre-configured with the following:

- **Next.js**: The React framework for production.
- **Tailwind CSS**: A utility-first CSS framework for styling.
- **ShadCN**: Pre-built UI components and utilities.
- **Redux Toolkit**: A modern approach to managing global state in React.
- **Next-Auth**: Authentication for Next.js applications.
- **Theming Support**: Built-in light/dark mode toggling.

---

## 🏗️ Project Structure

```
src/
├── app/            # Next.js pages
├── components/     # Reusable React components
├── lib/            # State management (Redux Toolkit), hooks, and utils
├── providers/      # providers hooks
```

## 🛠️ Getting Started

### Prerequisites

Ensure you have the following installed on your system:
- **Node.js**: Version 16 or later
- **npm** or **yarn**

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/your-repo.git
   cd your-repo
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

## 🌗 Theming

Switch between light and dark themes seamlessly using the built-in theme provider powered by Tailwind's dark mode. Customize themes in the `theme` directory.

---

## 🔐 Authentication

Easily integrate user authentication with **Next-Auth**. Configure providers and session management in the `pages/api/auth` directory.

---

## 🌍 Global State

Manage your application's global state using **Redux Toolkit**. Example slices are included in the `redux` directory.
